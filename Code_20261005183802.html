题4十种投资组合的利润曲线 ▼
题目

下面是几个投资组合，每一个都用术语Port来表示。画出每个人在t=T时的利润曲线。确定每个投资组合的优势和劣势，即解释一个理智的投资者对每种投资组合的期望是什么。

在这里，C_E表示行权价E的看涨期权，-C_E表示卖出看涨期权，P_E表示看跌期权，-P_E表示卖出看跌期权。

(a) "买入看涨期权"是Port=C_E。
(b) "卖出看涨期权"是Port=-C_E。
(c) "买入看跌期权"是Port=P_E。
(d) "卖出看跌期权"是Port=-P_E。
(e) "买入跨式"是Port=P_E+C_E，即以相同执行价格同时买入看涨和看跌期权。
(f) "卖出跨式"是Port=-P_E-C_E。
(g) "买入异价跨式"是Port=P_E1+C_E2，即以执行价格E1买入看跌期权，以执行价格E2买入看涨期权。
(h) "卖出蝶式"是Port=-C_E1+2C_E2-C_E3，其中E1<E2<E3。
(i) "买入蝶式"是Port=C_E1-2C_E2+C_E3，其中E1<E2<E3。
(j) "卖出鹰式"是Port=-C_E1+C_E2+C_E3-C_E4，其中E1<E2<E3<E4。
(k) "买入鹰式"是Port=C_E1-C_E2-C_E3+C_E4。

解题步骤
第1步：画图前的准备

横轴是到期日股价S_T，纵轴是利润。

看涨收益：max(S_T - E, 0)

看跌收益：max(E - S_T, 0)

卖出就是取负号。

(a) 买入看涨 C_E

S_T < E：不行权，收益0，亏权利金c。

S_T > E：行权，收益S_T - E - c。

形状：在E处拐折，右边斜率为+1。亏损有限（权利金），盈利无限。

(b) 卖出看涨 -C_E

买入看涨的反面。

S_T < E：赚权利金c。

S_T > E：亏 S_T - E - c。

形状：在E处拐折，右边斜率为-1。盈利有限（权利金），亏损无限。

(c) 买入看跌 P_E

S_T > E：不行权，收益0，亏权利金p。

S_T < E：行权，收益E - S_T - p。

形状：在E处拐折，左边斜率为-1。亏损有限，盈利有上限（最多E-p）。

(d) 卖出看跌 -P_E

买入看跌的反面。

S_T > E：赚权利金p。

S_T < E：亏 E - S_T - p。

形状：盈利有限，亏损有上限（最多E-p）。

(e) 买入跨式 P_E + C_E

同时买入相同执行价的看涨和看跌。

S_T ≈ E：两个都不行权，亏两份权利金。

S_T 远离E（大涨或大跌）：一边赚翻，覆盖另一边。

形状：一个V形，底部在E处。赌的是"大波动"。

优势：涨跌都能赚。劣势：如果股价不动，两份权利金都亏掉。

(f) 卖出跨式 -P_E - C_E

买入跨式的反面。

S_T ≈ E：赚两份权利金。

S_T 远离E：一边亏翻。

形状：一个倒V形，顶部在E处。赌的是"股价不动"。

优势：股价不动就赚。劣势：大波动会巨亏。

(g) 买入异价跨式 P_E1 + C_E2

看跌执行价E1，看涨执行价E2，通常E1 < E2。

S_T 在E1和E2之间：两个都不行权，亏两份权利金。

S_T 低于E1：看跌行权。

S_T 高于E2：看涨行权。

形状：一个较宽的V形，底部在E1和E2之间。比(e)的V更宽。

(h) 卖出蝶式 -C_E1 + 2C_E2 - C_E3

卖一个E1的看涨，买两个E2的看涨，卖一个E3的看涨。

形状：一个小的"尖顶"，在E2处利润最大。

赌的是股价停在E2附近。收益有限，风险有限。

(i) 买入蝶式 C_E1 - 2C_E2 + C_E3

卖出蝶式的反面。

形状：一个小的"尖底"，在E2处亏损最大，两边赚。

赌的是股价远离E2。风险有限，收益有限。

(j)(k) 鹰式

鹰式是蝶式的扩展，用四个执行价。

卖出鹰式：在E2到E3之间利润最大，是一个平台。

买入鹰式：反过来，在中间亏损最大。

形状比蝶式更平缓，适合预期股价在某个区间内波动。

第2步：总结各类组合的优缺点

单边买期权（a、c）：亏损有限，盈利可能很大。适合有明确方向判断的人。

单边卖期权（b、d）：盈利有限，亏损可能很大。适合想收权利金、愿承担风险的人。

跨式（e、f）：赌波动。买入跨式赌大动，卖出跨式赌不动。

蝶式/鹰式（h、i、j、k）：赌股价在某个区间。收益和风险都有限，适合精细判断。

涉及的概念（点击查看）： 收益图

横轴S_T，纵轴利润。画出来能一眼看出策略的盈亏结构。

跨式组合

同时买/卖看涨和看跌。买入跨式赌大波动，卖出跨式赌不动。

蝶式/鹰式

用多个不同执行价的期权组合，赌股价停在某个区间。收益和风险都有限。

权利金

买期权要付权利金，卖期权收权利金。这是所有组合成本/收益的起点。

题5比较买入跨式和买入异价跨式 ▼
题目

比较买入跨式组合和买入异价跨式组合的收益情况，并解释各自的优势。

解题步骤
第1步：回顾两个组合的定义

买入跨式：P_E + C_E，执行价相同。

买入异价跨式：P_E1 + C_E2，执行价不同（E1 < E2）。

第2步：对比收益结构

跨式：V形，底部是一个点（E）。股价必须远离E才能赚钱。

异价跨式：V形更宽，底部是一个区间（E1到E2）。股价只要在这个区间外就行。

成本对比：异价跨式的权利金通常更低，因为看涨执行价更高（看涨更便宜），看跌执行价更低（看跌更便宜）。

第3步：各自的优势

跨式优势：只要股价有任何大的波动，就能赚钱。适合预期"一定会大动，但不知道方向"的情况。

异价跨式优势：成本更低，容忍度更高。股价只要不在E1到E2之间就行，不需要剧烈波动。适合预期"股价会温和偏离"的情况。

涉及的概念（点击查看）： 跨式 vs 异价跨式

跨式：同一执行价。异价跨式：不同执行价。

异价跨式成本更低，但盈利门槛也更低。

波动率交易

买入跨式/异价跨式，本质上都是"做多波动率"。赌的是股价会动。

题6逆向构造投资组合 ▼
题目

这是关于投资组合的另一个问题。根据给定的利润曲线形状，设计投资组合。

(a) 构造一个投资组合，在t=T时刻，利润线是水平的，直到价格为60美元。在60美元这一点，利润曲线的斜率是3，直到70美元。在70美元这一点，利润曲线的斜率为2，直到价格为100美元。接下来，利润曲线的斜率为0，直到价格为110美元。然后利润曲线的斜率为-1，直到120美元。在那之后，利润曲线变得水平。

(b) 只使用看跌期权构造一个具有上述特征的投资组合。

(c) 同时使用看涨期权和看跌期权构造一个具有上述特征的投资组合。

解题步骤
第1步：理解斜率的变化

利润曲线的斜率，就是投资组合的Delta。

每当斜率变化，就意味着有一个期权在某个执行价处开始生效。

斜率变化点：60、70、100、110、120。

斜率变化量：

60处：从0变到3 → +3

70处：从3变到2 → -1

100处：从2变到0 → -2

110处：从0变到-1 → -1

120处：从-1变到0 → +1

第2步：斜率变化对应什么期权

看涨期权在行权价处，斜率+1。

看跌期权在行权价处，斜率-1。

斜率变化量+3 = 买入3份看涨（在60处）。

斜率变化量-1 = 卖出1份看涨（在70处），或者买入1份看跌。

斜率变化量-2 = 卖出2份看涨（在100处），或者买入2份看跌。

斜率变化量-1 = 卖出1份看涨（在110处），或者买入1份看跌。

斜率变化量+1 = 买入1份看涨（在120处），或者卖出1份看跌。

第3步：用看涨期权构造（a）

用看涨期权：

60处+3：买入3份C_60

70处-1：卖出1份C_70

100处-2：卖出2份C_100

110处-1：卖出1份C_110

120处+1：买入1份C_120

组合：Port = 3C_60 - C_70 - 2C_100 - C_110 + C_120

第4步：用看跌期权构造（b）

用看跌期权，斜率变化方向相反：

60处+3：卖出3份P_60

70处-1：买入1份P_70

100处-2：买入2份P_100

110处-1：买入1份P_110

120处+1：卖出1份P_120

组合：Port = -3P_60 + P_70 + 2P_100 + P_110 - P_120

（注意：这个组合和上面的看涨组合在到期日收益相同，因为看跌和看涨可以通过标的资产互相转换。）

第5步：同时用看涨和看跌（c）

可以自由选择每个拐点用看涨还是看跌。

例如：

60处+3：买入3份C_60

70处-1：买入1份P_70（等价于卖出1份C_70加上标的调整）

100处-2：买入2份P_100

110处-1：买入1份P_110

120处+1：卖出1份P_120

组合：Port = 3C_60 + P_70 + 2P_100 + P_110 - P_120

（需要调整标的资产头寸，使整体斜率匹配。）

涉及的概念（点击查看）： 斜率与Delta

利润曲线的斜率，就是组合的Delta。斜率变化点 = 期权的执行价。

逆向构造

给你利润曲线，倒推需要哪些期权。核心是看每个拐点处斜率变化了多少。

看涨/看跌的等价性

看涨和看跌可以通过"标的资产 + 债券"互相转换。所以同一个收益曲线，可以用不同方式构造。

题10完整套利操作 ▼
题目

假设目前，S=99美元，r=0.02，C_100(99,T-1/2) - P_100(99,T-1/2) = 8美元且T=t+1/2年。

(a) 判断目前有没有套利机会？如果有，应该如何操作？能获利多少？

(b) 虽然在未来的6个月中，任何情况都有可能会发生，不过我们至少可以保证在到期日时你的资金安全。请列出所有可能的情况，说说你是如何保证清偿债务并实现获利的。

解题步骤
第1步：写出平价关系式

C - P = S - E × e^(-r(T-t))

已知：S=99，E=100，r=0.02，T-t=0.5年。

右边 = 99 - 100 × e^(-0.02×0.5) = 99 - 100 × e^(-0.01)

e^(-0.01) ≈ 0.99005

右边 = 99 - 99.005 = -0.005

左边 = 8（题目给的C-P值）。

第2步：发现套利机会（a）

左边8，右边-0.005。左边 > 右边。

说明C-P被高估了，即C太贵，或者P太便宜。

套利方向：卖出C，买入P，卖空股票，存钱。

第3步：构造套利组合

1. 卖出看涨期权 C_100：收C

2. 买入看跌期权 P_100：付P

3. 卖空股票：收99

4. 存入银行：存 99 + C - P = 99 + 8 = 107（因为C-P=8）

初始现金流：-C + P + 99 - 107 = -C + P + 99 - (99 + C - P) = 0。完美。

第4步：到期日分析（b）

半年后，存款变为：107 × e^(0.02×0.5) = 107 × e^0.01 ≈ 107 × 1.01005 ≈ 108.08

到期日，看涨和看跌组合的收益：

如果S_T > 100：看涨被行权，你按100卖出股票，得100。看跌归零。

如果S_T < 100：看跌行权，你按100买入股票，得100。看涨归零。

无论哪种情况，你都能用100美元平掉股票空头。

净赚 = 108.08 - 100 = 8.08美元。

第5步：验证资金安全

无论股价涨到多少还是跌到多少，你在到期日的净收益都是8.08美元。

因为看涨和看跌的组合，保证了你能按100美元买入/卖出股票。

银行存款108.08，足够支付100美元的股票平仓成本。

这就是无风险套利。

涉及的概念（点击查看）： 套利

平价关系式被打破时，通过买卖组合锁定无风险利润。

卖空股票

借股票卖出，到期时买回还回去。这里用来构造套利组合。

资金安全

通过组合，无论股价怎么变，到期都能清偿债务。这就是"无风险"的含义。

平价关系式

C - P = S - E·e^(-rT)。这是判断套利机会的核心工具。

期权价格不是随便定的，它们之间必须满足平价关系式。一旦偏离，套利者就会冲进去，把价格拉回来。

这就是"无套利"的力量，也是第2章的灵魂。
